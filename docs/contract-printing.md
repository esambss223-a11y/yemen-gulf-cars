# تصميم الاستلام والعقد والطباعة

شاشتا الاستلام وتفاصيل العقد تستخدمان FleetDialog وألوان fleet-theme وحقول النموذج
الموحدة. تبقى حسابات التأخير والنظافة والأضرار والتأمين كما كانت؛ تجمعها الدالة
النقية calculateReturnSettlement، مع اختبارات على الغرامة بالساعة واليوم
والرصيد المسترد والمبالغ الإضافية. نموذج الاستلام يبدأ بحالة مستقلة لكل عقد.

## فصل الطباعة

- RentalContractDocument مكوّن المستند المشترك بين المعاينة والطباعة.
- يعرض RentalContractView التفاصيل أو معاينة مصغّرة دون تمرير أفقي على الهاتف.
- نسخة الطباعة توضع مباشرة تحت body عبر React portal، خارج حاويات لوحة التحكم.
- contract-print.css يخفي بقية الواجهة فقط عند وجود نسخة العقد هذه، ويخصص صفحة
  A4 بهامش 10 ملم، مع إبقاء الفقرات والتوقيعات قابلة للانتقال إلى الصفحة التالية.
- الزر ينتظر الشعار والخطوط ثم يفتح نافذة الطباعة. Ctrl+P يستخدم المستند نفسه.
- يحفظ المستند أرقام العقد والهوية والمواعيد والمبالغ والملاحظات وبنود العقد
  الأربعة الحالية. رقم الشركة مأخوذ من COMPANY_CONTACT.
- لا تسجّل الطباعة أي مدفوعات أو توقيع أو تعديل على الحجز.
