# Frontend Design System Skill

## Project

This project is the official website for:

شركة اليمن والخليج لتوريد السيارات

The website must feel premium, modern, trustworthy, automotive, and editorial.

The design must NOT look like a generic AI-generated website.

## Core Design Principles

- Do not generate generic AI website patterns.
- Do not use gold/black luxury styling unless explicitly requested.
- Do not use excessive gradients.
- Do not use excessive glassmorphism.
- Do not use oversized decorative icons.
- Do not use random floating shapes.
- Do not use unnecessary cards.
- Do not use excessive rounded corners.
- Do not use visual effects just because they are technically possible.
- Avoid generic SaaS layouts.
- Avoid generic template-like sections.

Every visual decision must have a clear design reason.

## Brand First

The design system must be established before building the complete website.

Do not invent brand colors, typography, imagery, or visual language without discussing them first.

Once a design decision is approved, treat it as part of the design system and do not change it without approval.

## Layout

Prioritize:

- Strong composition
- Clear hierarchy
- Generous whitespace
- High-quality typography
- Large editorial imagery
- Consistent spacing
- Strong grid systems
- Responsive behavior

## Motion

Motion must be intentional and subtle.

Do not animate every element.

Use animation to:

- establish hierarchy
- guide attention
- reveal content
- create continuity between sections
- enhance the hero experience

Prefer smooth, cinematic motion over flashy effects.

## Code Quality

- Use reusable React components.
- Keep sections modular.
- Keep content separate from presentation where appropriate.
- Do not create unnecessarily large components.
- Do not install new libraries without explicit approval.
- Do not modify unrelated files.
- Do not rewrite working code without a reason.

## Libraries

Do not install GSAP, Lenis, Swiper, Three.js, React Three Fiber, Framer Motion, or other animation/3D libraries unless explicitly instructed.

## Important Rule

Before implementing a major visual feature:

1. Explain the intended design.
2. Explain which files will be changed.
3. Explain which libraries are required.
4. Wait for approval if the change introduces a new library or major architectural decision.
